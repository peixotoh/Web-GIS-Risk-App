🗺️ API Endpoint Testing Tool

Test GeoJSON API endpoints and visualize data on an interactive map

📋 Example API Endpoints:

  • GeoJSON: https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson
  • Swiss Admin: https://data.geo.admin.ch/ch.swisstopo.swissboundaries3d-gemeinde-flaeche.fill/
  • Local file: ./data/json/ti_buildings.geojson
Instructions: 1. Enter a GeoJSON API endpoint URL in the input field above 2. Click "Load Data" to fetch and display the data on the map 3. The map will automatically fit to the data bounds (if enabled) 4. Click on features to see their properties in popups 5. Use "Clear Map" to remove all loaded data

Supported Geometries: Points, LineStrings, Polygons, MultiPoints, MultiLineStrings, MultiPolygons
